# 零区冲突 · NEON ARENA
- **在线体验链接**
http://fps.zard.loc.cc/

3D 第一人称多人在线混战射击游戏。一个 URL，多个客户端直接进入同一房间开打 —— 无需注册、无需下载。

> **项目来源**：本项目由 [kejilion/game-collection · neon-arena-fps](https://github.com/kejilion/game-collection/tree/main/games/neon-arena-fps) **二次开发**而来，在其基础上进行功能扩展与玩法改动。

- **服务端**：Node.js（express + ws），单房间权威服务器，所有伤害/拾取/购买均在服务端判定
- **客户端**：Three.js 第一人称，全部模型/贴图/音效程序化生成，零外部资源
- **持久化**：排行榜与玩家档案（金币/外观）按 **IP** 索引保存在 `data/profiles.json`；昵称全局唯一，改名只更新该 IP 账号，不会新建账号

## 打击感

命中反馈是一整条链路，不是单加个音效：命中瞬间视角会朝攻击方向弹一下（弹簧阻尼式回弹，比纯随机抖动更"扎实"）；近战命中额外给一记前顶力道，铁锤最沉、小刀最脆；被打的玩家/BOSS 会有短促的后仰位移或挤压反应；子弹打空/打墙会在终点补一个环境命中火花，不再是"消失了事"；暴击/爆头的准星弹出动画单独放大；音效上给命中/爆头叠加了低频瞬态增加"肉感"，近战命中按武器分量级。这些全是客户端表现层的东西，服务端只多广播了一个武器类型字段，伤害计算和命中判定完全没动。

## 玩法

- 随机地点出生，初始只有**拳头**；死亡后换地点重生（重生有 2.5s 保护）
- **场地尺寸**：整体战场扩为 **96x96**（外墙 ±48），没有内环分隔，外围空间直接并入主战场。
- **地形**：两处高地平台（台阶可上）搭配外围掩体，可卡点也可被手雷洗地；**红色油桶可被打爆**，殃及半径 4.5m 内所有人（会连锁！），30~45s 后重生
- **昼夜交替**：10 分钟一昼夜，清晨/白天/黄昏/深夜光照与天空实时变化，夜晚霓虹灯柱亮起（左上角有时段指示）
- 场内 18 个拾取点自动刷新三类物品（走近自动拾取）：
  - **武器**：小刀 / 长刀 / 铁锤 / 手枪 / 散弹枪 / 机枪 / 狙击枪 / 电磁炮 —— **有限备弹**，越强的枪备弹越少（手枪 156 发 / 散弹枪 66 发 / 机枪 360 发 / 狙击 35 发 / 电磁炮 3 发不可换弹），打空当前匣自动换弹（消耗备弹），**备弹打光会提示"用光了"，玩家自己去武器点换新枪**（空枪留在手里）；狙击枪、电磁炮右键开镜；散弹枪近距离 8 弹丸齐射；电磁炮共 3 发、射完即空、不可换弹，留下电光轨迹
  - **投掷物**（三选一，拾取替换，携带有限个）：💣**手雷** ×5 范围爆伤（引信 4s，按住捏雷、松手投掷，可温雷瞬爆，冷却 2s）；🔆**闪光弹** ×6 致盲正对爆点的敌人，越近越正对白得越久，视线被墙挡住免疫（引信 1.3s，可温雷，冷却 1.6s）；💨**烟雾弹** ×8 15 秒视野遮蔽，烟中名牌隐藏、手机端辅助瞄准同样失效（引信 1.4s，可温雷，冷却 1.6s）。用光同样提示、自行补给
  - ⚙️ **补给方式**：不单独捡子弹——**拾取任意武器点即弹药满血**（同款枪=补弹，新枪=换枪满弹；投掷物点补满个数）
  - **装备**：医疗包(+50血) / 防弹衣(+50甲) / 疾风靴(永久+10%移速，最多3层)
  - **状态道具**：⚡疾速 / 🔥狂暴 / 💥暴击 / 👻隐身 / 🧟暴走丧尸(只能近战·伤害25·100%吸血) / 🦘弹跳 / 🛡️护盾
- **五种特色 BOSS** 随机降临（同场仅一只），击杀得金币 + 满血 + 随机增益，助攻也有金币：
  - 🪨 **熔岩魔像**：近战重击 + 火球（200🪙）
  - 🗡️ **暗影刺客**：高速突进，会闪现到你身后、周期隐身（180🪙）
  - 🤖 **钢铁暴君**：1400 血重装机体，弹幕连射 + 三连火箭（280🪙）
  - 💀 **虚空巫妖**：追踪法球 + 脚下紫圈延迟爆破，看到圈快跑！（220🪙）
  - 💗 **Amiya_desi · 嫉妒魔女**：因果延迟 + 死亡回归 + 不可视之手 + 嫉妒之影（280🪙），详见下方
- **神秘商人**（地图四角各一处摊位，按 E）：金币购买**枪械**（弹匣+备弹满配）或头部/面部/背部/武器光效等外观装饰；**商店内置 3D 预览**，悬停即试穿/试枪；外观按 IP 账号永久保存，枪械即时生效
- **击杀奖励**：+100 分 +25 金币 +15 血；连杀有全场播报
- **聊天**：回车发送；**排行榜**：按 Tab（实时榜 + 历史榜，击杀数优先，并列时**连杀**更高者靠前）。实时榜末列显示当前连杀、历史榜显示历史最高连杀，主菜单也展示历史榜
- **观战模式**：菜单进入或阵亡后选择，自由飞行视角（WASD+空格/C，滚轮调速），按 F 跟随玩家（←/→ 切换，默认第三人称，V 切第一人称），回车随时加入战斗
- **设置**（ESC）：背景音乐、音效开关，鼠标灵敏度，视角切换

## 移动端 / 跨端公平性

手机浏览器打开同一个 URL 可以和电脑玩家同场竞技，专门做了以下适配，目标是**手机不是弱势群体**：

- **触屏操作**：左下角虚拟摇杆（浮动式，触点落下即生成）负责移动；屏幕其余区域拖拽控制视角；右下角圆形按钮负责开火(◎，持枪自动挂机枪连发)/跳跃(⤒)/狙击镜(🔭，持狙击枪时才出现)；右上角 ☰设置 🏆排行榜 💬聊天。武器栏（HUD 下方三个格子）改为点按切换，再点一次已激活的枪械格 = 换弹，省掉一个按钮
- **子弹磁吸辅助瞄准**：仅触屏客户端生效——开火方向如果 7° 锥角内有敌人，会在客户端本地朝目标中心柔性纠偏最多 35%（不是 100% 锁定），用来补偿手指精度天生低于鼠标这件事；桌面端这段代码完全不跑，服务器判定逻辑对两端一视同仁，没有任何后门
- **画质自适应**：按设备算力分三档（阴影分辨率 2048/1024/512、抗锯齿开关、像素比上限），持续帧率过低还会自动砍阴影救场。**红线是视距和雾距离永远不缩短**——看得多远、看得见多远的敌人，两端必须完全一致，画质分级只动阴影/抗锯齿这类纯观感开销
- **轻量背景音乐**：程序化合成、零音频文件；标签页切后台自动停止音乐调度省电；移动端默认精简和弦垫与镲片密度（`lite` 模式），进一步降低同时发声的振荡器数量
- 安全区适配（刘海屏）、`touch-action` 防止游戏区域被系统手势/双指缩放打断、面板加了 × 关闭按钮（桌面也能用）

用 `?touch=1` / `?touch=0` 可以在任意设备上强制切换触屏 UI 便于调试，`?quality=high|medium|low` 强制画质档位。

## 本地运行

```bash
npm install
npm start        # 默认 http://localhost:3066
```

浏览器打开 `http://localhost:3066`，多开几个标签页即可体验联机。

## Android App（Capacitor）

仓库已包含 `android/` Android Studio 工程。App 内置 `public/` 前端资源，联机时固定连接
`http://fps.zard.loc.cc/`，支持横屏沉浸模式、屏幕常亮、触控操作与陀螺仪瞄准。

```bash
npm install
npm run android:sync   # 修改 public/ 后同步到 Android 工程
npm run android:open   # 用 Android Studio 打开
```

在 Android Studio 中等待 Gradle 同步完成，连接已开启 USB 调试的手机后点击 Run。生成 APK：

```bash
cd android
gradlew.bat assembleDebug
```

调试包输出到 `android/app/build/outputs/apk/debug/app-debug.apk`。线上地址目前是 HTTP，
因此 Android 工程已显式允许明文 WebSocket；改为 HTTPS 后应同步把
`public/js/game.js` 中的 `NATIVE_GAME_ORIGIN` 改成 HTTPS，并关闭 cleartext 配置。

## Docker 部署

```bash
# 方式一：docker compose（推荐，含数据卷与自动重启）
docker compose up -d --build

# 方式二：手动构建
docker build -t neon-arena-fps .
docker run -d --name neon-arena \
  -p 3066:3066 \
  -v /opt/neon-arena/data:/app/data \
  --restart unless-stopped \
  neon-arena-fps
```

部署完成后，把 `http://服务器IP:3066` 发给朋友即可同场竞技。`/health` 返回在线人数等状态，可接入监控。

### 反向代理（可选，启用 HTTPS/域名）

WebSocket 与页面同端口同路径，Nginx 需开启 Upgrade 透传：

```nginx
location / {
    proxy_pass http://127.0.0.1:3066;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
}
```

页面走 HTTPS 时客户端会自动使用 `wss://`，无需额外配置。

## 反作弊

服务端权威 + 通用反作弊引擎，默认开启。所有伤害、位移、拾取、购买均由服务器裁决，客户端消息只作"请求"。

- **移动校验**：瞬移当场回拉、加速/飞天/穿墙漏桶判定（容忍网络抖动，其他玩家永远看到合法位置）
- **网络尖峰豁免（防误封）**：包间隔异常大（丢包/卡顿恢复）时，那一包只回拉位置、**不计违规分**——卡顿玩家不被冤枉，外挂即便刻意慢发也照样被回拉、超豁免额度后照样被抓。瞬移阈值随包间隔动态放大，弹跳/疾速道具的高度和速度边界也做了宽限，人多网络波动不再误触封禁。
- **射速校验**：冷却时序收口，连点宏/射速外挂无效
- **限速**：分消息类型令牌桶，抵御洪泛
- **瞄准统计**：爆头率/命中率/甩枪特征滚动窗口分析（阈值保守，只抓离谱者）
- **阶梯处置**：纠正 → 警告 → 踢出 → 封禁（IP+昵称，24h 内多次被踢自动升级封禁，持久化落盘）

`GET /health` 暴露 `anticheat` 实时指标（flags/kicks/bans）。设 `AC_MODE=off` 可关闭惩罚（用于压测/调试，冷却与数值等功能校验仍生效）。封禁记录在 `data/anticheat.json`，删除对应键即手动解封。

引擎已抽象为**零依赖、可移植的通用库**（`server/anticheat/`），可直接复制到任何 Node 多人对战服务器复用，接入方法、API 与调参 checklist 见 [server/anticheat/README.md](server/anticheat/README.md)。

## Zard 假人

服务器默认随 `npm start` 自动上线一名名为 **zard** 的假人，走与真人相同的 WebSocket 协议，在 3D 场景、在线人数、系统消息里与真人无异，用于营造服务器有人的氛围。

**行为特征：**
- 随机漫游，自动拾取武器/补给
- BOSS 刷新后会主动参战（射击、近战），但服务端对其 BOSS 伤害为真人的 **50%**
- 低侵略性 PvP（约 15% 概率追真人），瞄准误差大、偶尔打空
- 死亡后自动复活，断线 3 秒内重连

**不计入排行榜：**
- 不出现在 Tab 实时榜
- 击杀/死亡/BOSS 击杀/金币/外观不写入 `profiles.json`
- 击杀 zard 无分数/连杀奖励；zard 击杀真人时真人正常死亡但 zard 不得奖励

**击杀彩蛋（按昵称累计）：**
- 累计击杀 zard **5 次**：私密提示「再杀 10 次 ??? 会触发彩蛋」
- 累计击杀 zard **15 次**：+1000 金币 + **开发者奖杯**（可装备为背饰）；全场聊天 zard 求饶
- 持有开发者奖杯后 zard 不再攻击你；可在神秘商店 / 衣橱 **背部** 栏装备奖杯背饰

关闭假人：`DECOY_ENABLED=off npm start`

## Amiya_desi · 嫉妒魔女

致敬社区玩家 [Amiya_desi](https://blog.sayori.org/posts/ziwojieshao/self-introduction/) 的彩蛋 BOSS（灵感来自 Re:Zero 的「死亡回归」等权能）。与其他 BOSS 同等随机降临，同场仍仅一只；击杀奖励 280 金币 + 满血 + 随机增益。

**技能（机制均为本 BOSS 独有，不复用刺客闪现/巫妖法球）：**

| 技能 | 说明 |
| --- | --- |
| **因果延迟** | 打中她的伤害不会立刻掉血，约 **3 秒**后才结算；HUD 显示「未定之死」待结算量 |
| **死亡回归** | 场上有粉色**记录点**；本场**第一次**本应被打死时，会读档回到记录点并清空未结算创口，全场公告「——从零开始。」；**第二次**才真正击杀 |
| **不可视之手** | 紫色的手从魔女**背后四角**（左上/右上/左下/右下）伸出，**触须可无限延伸**追击全图；**初速较慢，约 7 秒加速到顶峰**；发动时全场提示可攻击打断；**血量 1，子弹可穿透**（一枪可同时打碎路径上多只）、近战一击即碎、**目标死亡/离场**时立刻收回；打碎后她短暂眩晕 |
| **嫉妒之影** | 脚下铺开影域预警圈（范围较大），**约 2.5 秒后延迟爆炸**；预警期间不扣血，爆炸时范围伤害 |
| **暗影爪击** | 贴身近战保底 |

**对抗要点：** 要么在因果延迟窗口内把伤害叠满并在她读档前结算掉，要么先打碎不可视之手逼出眩晕再输出；看到粉色影圈立刻离开，别站着等炸。第一次「击杀」多半只是死亡回归，别松懈。

**忌语制裁：** 该 BOSS 在场时，公屏发送 `死亡回归` / `return by death` / `rebd`（不区分大小写）不会正常广播，发言者会被影制裁。日常聊「Re0」「从零」不会触发。

**真人彩蛋：** NodeLoc 账号对应的 Amiya_desi 本人击杀该 BOSS 时，会收到一条仅自己可见的私密提示。


数值与文案在 [server/config.js](server/config.js) 的 `BOSSES.amiya` / `EGG_AUTH`；AI 与创口结算在 [server/world.js](server/world.js)。
